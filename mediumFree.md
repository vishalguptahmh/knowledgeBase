Setup:
  1. Show your bookmarks bar (Ctrl+Shift+B / Cmd+Shift+B).
  2. Right-click the bar → Add page (or Add bookmark).
  3. Name: anything, e.g. "Prefix URL".
  4. URL: paste one "javascript:location.href="https://freedium-mirror.cfd/"+location.href;"
  5. Save. Click it on any page — same effect as the extension button.
