# Knowledge Base

A personal collection of software-engineering notes: system design, data
structures & algorithms, Android, AI/LLM security, cloud, and interview
preparation.

```
docs/   written notes, grouped by topic (see Contents below)
code/   runnable snippets referenced from docs/ (java/, python/dsa/)
assets/ images, diagrams, PDFs, audio referenced from docs/
```

Filenames are lowercase kebab-case with a `.md` extension. New notes go
under the existing topic folder that fits best; only add a new top-level
folder under `docs/` for a genuinely new subject.
